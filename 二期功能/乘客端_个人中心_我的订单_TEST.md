# 乘客端个人中心「我的订单」二期 TEST

> 本文档用于「我的订单」页面的验收回归。
> 接口见《乘客端_个人中心_我的订单_API.md》，产品口径见《乘客端_个人中心_我的订单_PRD.md》。

## 0. 测试范围

- 个人中心入口可见
- 列表可查
- 三种筛选可切换
- 列表按时间倒序
- 每条订单展示 3 个按钮占位
- 按钮本期不触发真实业务

---

## 1. 环境准备

- `gateway`、`passenger-api`、`order` 可用
- 乘客账号可登录
- 数据库中存在至少 3 笔不同状态的乘客订单

---

## 2. 接口测试

### T-PO-01 查询全部订单

- **接口**：`GET /app/api/v1/orders?type=ALL`
- **前置**：当前乘客存在历史订单
- **预期**
  - 返回本人订单
  - `list` 按时间倒序
  - `total` 正确

### T-PO-02 查询待出发订单

- **接口**：`GET /app/api/v1/orders?type=TO_DEPART`
- **前置**：当前乘客存在 `CREATED / ASSIGNED / PENDING_DRIVER_CONFIRM / ACCEPTED / ARRIVED` 状态订单
- **预期**
  - 仅返回上述状态订单
  - 不返回 `FINISHED / CANCELLED`

### T-PO-03 查询退款与取消订单

- **接口**：`GET /app/api/v1/orders?type=REFUND_CANCEL`
- **前置**：当前乘客存在已取消订单
- **预期**
  - 仅返回 `CANCELLED`
  - 列表卡片展示取消信息

### T-PO-04 按钮占位

- **接口**：`GET /app/api/v1/orders`
- **预期**
  - 每条订单返回 3 个按钮
  - 按钮文案分别为：
    - `申请开票`
    - `呼叫返程`
    - `评价`
  - 当前均为禁用或未实现状态

## 3. 页面验收

### T-PO-05 个人中心入口

- **步骤**
  1. 登录乘客端
  2. 进入个人中心
  3. 点击「我的订单」
- **预期**
  - 能进入订单列表页

### T-PO-06 筛选切换

- **步骤**
  1. 打开「全部」
  2. 切换到「待出发」
  3. 切换到「退款与取消」
- **预期**
  - 每个筛选展示与接口一致的数据

### T-PO-07 倒序展示

- **步骤**
  1. 准备多笔不同创建时间的订单
  2. 打开列表
- **预期**
  - 新订单排在前面

### T-PO-08 按钮展示

- **步骤**
  1. 查看任意订单卡片
  2. 点击 3 个按钮
- **预期**
  - 按钮可见
  - 本期不触发真实业务
  - 如有提示文案，应明确为“功能开发中”或等价提示
