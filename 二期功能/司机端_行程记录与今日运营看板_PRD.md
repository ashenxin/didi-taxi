# 司机端行程记录、详情与今日运营看板 PRD

> 2026-09-06 用户已确认本期业务口径。数据库由用户手动执行，代码及测试进展见同名 TEST。

## 1. 范围与入口

司机首页展示今日运营看板；“行程记录”进入历史列表，点击记录或最近完成行程进入详情。
列表包含全部、进行中、已完成、已取消，可按日期查询、分页、下拉刷新，并提供空态、错误重试和返回工作台入口。
查看历史期间继续听单心跳和接单通知；有待确认订单或进行中行程时可随时返回工作台。
本期不实现司机钱包、提现、净收入和车队分成配置。

## 2. 记录边界（已确认）

- 成功接单开始一条司机服务记录；拒单、确认超时、未接单指派不属于行程。
- 接单后取消仍保留记录。司机 A 取消后司机 B 完成同一乘客订单：A 看到自己的取消，B 看到自己的完成。
- 列表和详情使用行程记录 ID；订单号用于展示。一张乘客订单可以对应多条司机服务记录。
- 改派不允许前一司机查看下一司机的时间线、账单或服务车辆。换队也不改写历史归属。
- 记录筛选：IN_PROGRESS 对应已接单/已到达/行程中，FINISHED 对应已完成，CANCELLED 对应已取消。
- 取消区分司机、乘客、系统；司机退出登录导致已接未到释单归入司机取消，展示退出登录原因。不据此计算责任或处罚。

## 3. 展示字段

列表：订单号、起终点、接单时间、状态、最终订单金额；没有最终金额时展示结算中或未结算，不以预估冒充最终。
详情：订单号、城市、车型、当次车辆/车队标识、下单/接单/到达/开始/完成或取消时间、取消方及原因、预估金额、最终车费、优惠、应付、已付、结算状态、里程和时长。
历史名称或数据无法证明时展示“未记录”，不使用司机当前车辆/车队冒充历史快照。首期车辆/车队以历史 ID 展示。
客服入口提示通过平台客服渠道联系，不承诺尚未建设的工单能力。

## 4. 金额和时间

- 订单金额 = trip_order_settlement.final_amount（优惠前最终车费），包含已定价但未支付的完成单；不等于司机净收入。
- 最终金额未生成时不计入总金额，展示待计价单数。需人工处理的异常结算不计入金额总计，并提示异常单数。
- 取消记录不展示订单后续账单，不计入完成金额、服务里程和时长。
- 今日按 Asia/Shanghai 自然日的 [00:00, 次日00:00)；完成数和金额按完单时间归属，取消数按当次取消时间归属。
- 服务时长为开始至完单的非负时间差，不含接驾等待；计费时长使用结算冻结字段，单独展示。
- 里程沿用下单冻结值；当前为 Mock 路线，页面注明数据来源。缺失里程/时长不猜测，汇总提示缺失条数。

## 5. 看板和刷新

完成单数、订单金额、完成行程里程、服务时长、取消数、最近完成行程。
点击完成类指标进入今日已完成记录（按完单日），点击取消进入今日已取消记录（按取消日）。
支持手动刷新、登录/回到首页刷新、完单与取消后刷新、页面恢复可见/跨日刷新。
完单后结算可能异步完成，对结算中的数据执行有上限的刷新，达到上限保留手动刷新。

## 6. 验收

跨司机、重复动作、改派、跨天、支付未完成、结算异常、空数据和网络错误详见 TEST。
历史数据由用户手动回填；回填前旧订单不保证全部出现在记录页，缺失证据不伪造。
