# 司机端行程记录、详情与今日运营看板 TEST

> 2026-09-07。下列为验收口径及本次自动化执行结果；业务 MySQL 与真实网关联调仍按第 5 节执行。

## 1. 记录与状态

- 成功接单仅生成一条记录；同 key 重放和已接单重复动作不重复生成。
- 接单→到达→开始→完成，时间线与状态一致；记录更新失败时订单状态和事件一起回滚。
- 司机 A 接单后取消，改派 B 并完成：A 仅见自己的取消记录，B 仅见自己的完成记录。
- 拒单和确认超时不生成记录；接单前的乘客取消不生成记录。
- 已接单乘客取消保留司机记录；退出登录释单保留司机取消原因。
- 同司机再次服务同一订单时使用新的记录 ID，幂等重放不新建。

## 2. 查询与权限

- 未登录401；其他司机的行程记录404；伪造 query driverId 不改变身份。
- 全部/进行中/已完成/已取消、日期边界、非法参数、空态符合 API。
- 同秒接单排序稳定；后续新增记录不进入已固定 snapshotId 的后续分页。
- 取消记录不展示后续司机的时间线、最终车费、优惠、已付金额和计费时长。
- 换队后仍展示历史车辆/车队ID，缺失名称不猜测。

## 3. 看板

- 上海时区跨午夜完成归完单日、取消归取消日；区间右端不计入。
- 完成数包含尚在结算的单，金额不使用预估补值；异常结算和缺失里程/时长有提示。
- finalAmount 与 paidAmount 不同，汇总使用前者；0元合法金额正确显示。
- 服务时长取开始到完成，计费时长单独显示；取消不计入完成里程与时长。
- 指标跳转列表使用对应时间口径，最近完成行程正确。

## 4. H5 交互与回归

- 列表分页/下拉刷新/日期筛选/详情返回/网络失败重试。
- 切换筛选后旧请求不覆盖新结果；退出登录后旧账号数据清理。
- 历史页不影响听单心跳，待确认与进行中行程可返回工作台处理。
- 完单后刷新看板，结算延迟时有限刷新；跨日和恢复可见刷新。
- 登录、主操作、错误态、退出登录及原有换队入口回归。
