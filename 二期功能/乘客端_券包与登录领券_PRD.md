# 乘客端「券包与登录领券」PRD

> 记录日期：2026-07-13
> 范围：首页底部「券包」、个人中心「我的钱包-可用优惠」、登录后优惠券领取弹框、账号注销后的优惠券处理。
> 状态：功能代码已完成，待 SQL、配置、历史数据与测试环境联调确认。

---

## 1. 背景

后台已支持在车队计价规则下配置优惠券方案。乘客端需要在登录、首页券包、个人中心钱包三个位置承接优惠券能力：

- 登录后发现可领取券，主动弹出领取入口。
- 首页「券包」展示乘客当前可用券，按失效时间正序排列。
- 个人中心「我的钱包-可用优惠」展示同一批用户券。
- 账号注销后，旧账号未使用券应自动作废。
- 同一手机号领取过某模板券后，注销再注册也不能重复领取该模板券。

---

## 2. 产品目标

1. 提升乘客对优惠券的感知，登录后能明显看到可领取优惠。
2. 首页券包和个人中心优惠券数据一致，不做两套业务逻辑。
3. 乘客可自主选择逐张领取或全部领取，不强制领取。
4. 防止通过注销、重新注册同一手机号重复领取同一模板券。
5. 注销后清理旧账号未使用券，避免旧账号资产残留。

---

## 3. 功能范围

### 3.1 登录领券弹框

触发时机：

```text
乘客登录成功后，前端调用可领取券接口。
接口返回可领取券数量 > 0 时，页面内展示弹出样式领券框。
```

展示内容：

- 券名称。
- 优惠金额或折扣。
- 使用门槛。
- 适用城市、产品线、发券车队。
- 有效期结束时间。

交互：

- 每张券有「领取」按钮。
- 支持「全部领取」。
- 支持「暂不领取」关闭弹框。
- 领取成功后刷新钱包摘要、首页券包和个人中心优惠券列表。

不做：

- 不用勾选框批量选择。
- 不强制领取。
- 不跳出当前打车页面，不遮挡成固定页面模块。

### 3.2 首页券包

首页底部「券包」展示当前登录乘客可用券。

排序：

```text
validEndAt ASC
id DESC
```

展示：

- 一张张列出可用券。
- 快过期券优先出现在前面。
- 无券时展示空状态。

当前「去使用」一期可先作为入口占位，后续可改为跳回打车首页或进入下单流程自动带出可用券。

### 3.3 个人中心可用优惠

路径：

```text
个人中心 -> 我的钱包 -> 可用优惠
```

与首页券包使用同一接口、同一用户券数据。

需要展示：

- 券名称。
- 优惠规则。
- 门槛。
- 适用城市/产品线。
- 发券车队。
- 券状态。
- 有效期。

### 3.4 账号注销后的优惠券处理

注销前：

- 如果存在进行中订单，禁止注销。
- 如果存在未结清订单，禁止注销。
- 如果存在 `LOCKED` 优惠券，禁止注销。

注销成功后：

- 旧账号 `UNUSED` 券置为 `INVALID`。
- `USED` 保留，用于订单、结算与审计。
- `EXPIRED` 保持不变。
- 写入 `INVALIDATE` 流水。

### 3.5 同手机号重复领取风控

产品定版：

```text
手机号领取过该券后，注销再登录，无权再领取。
```

解释：

- “该券”按 `coupon_template.id` 判断。
- “手机号”按手机号哈希判断，不存手机号明文。
- 旧券无论是 `UNUSED / LOCKED / USED / EXPIRED / INVALID`，只要历史领取过，就不能再次领取同模板券。

---

## 4. 业务规则

### 4.1 可领取券规则

模板必须同时满足：

- 状态为 `PUBLISHED`。
- 未删除。
- 当前时间在模板有效期内。
- `received_count < total_count`。
- 当前乘客未领取过该模板。
- 当前手机号身份未领取过该模板。

### 4.2 领取规则

- 单张领取：乘客点击某张券领取。
- 全部领取：领取当前接口返回的全部可领取券。
- 重复点击同一张券时，后端按幂等跳过，不重复发券。
- 库存不足或已领取时，该券跳过，不影响其他券领取。

### 4.3 用户券列表规则

默认查询 `UNUSED` 可用券。

支持状态：

```text
UNUSED / LOCKED / USED / EXPIRED / INVALID
```

首页券包只展示 `UNUSED`。

---

## 5. 验收标准

- 登录后有可领取券时弹框明显展示。
- 单张领取成功后，该券从可领取列表消失，并出现在券包/个人中心可用优惠。
- 全部领取后，可领取券列表清空，钱包摘要数量增加。
- 首页券包按失效时间正序展示可用券。
- 个人中心可用优惠数量与钱包摘要一致。
- 同一手机号注销后重新注册，不再能领取旧手机号已领取过的同模板券。
- 注销旧账号后，旧账号未使用券变为 `INVALID`。
- 有锁定券时，注销被阻止。

---

## 6. 暂不纳入本期

- 多券叠加。
- 优惠券转赠。
- 设备指纹、实名、支付账号等更强风控。
- 首页券包专属券。
- 福利签到发券。
