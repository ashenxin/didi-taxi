# 乘客端 AI 客服：天气查询 skill PRD

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.0 |

| 产品范围 | AI 客服内的单城市、单日天气（预报）查询 |
| 技术约束 | 复用高德 Web 服务 API 与现有 `map-service` 内部鉴权 |

## 1. 背景与目标

AI 客服已支持路线规划、当前路线核查和指定途经点。天气是独立的轻量问答能力：乘客在同一个客服会话里可以直接问“杭州明天天气”“明天会下雨吗”，不需要先建立路线。

第一版的目标是提供一个**无长期状态、可复用**的天气 skill：

- 一次问答的天气事实只依赖“城市 + 日期”；同会话天气追问可由 passenger-api 复用上一轮天气回答的城市或待补城市上下文，但不依赖当前路线、地图页状态或完整聊天历史；
- 天气事实只来自高德预报，模型和客户端不能编造温度、天气现象或风力；
- skill 只返回结构化结果，不自行向用户提问；由 passenger-api 组织话术；
- 不改变任何路线状态，也不影响已有路线卡片和核查上下文。

## 2. 第一版范围

### 2.1 支持

- 单城市或区县：如“杭州”“西湖区”“湖州德清”。
- 今天、明天、后天、大后天四天。
- 文本回答；必要时附带 `weather` 结构化 payload。
- 缺城市时请乘客补充完整问法，例如“杭州明天天气”。
- 日期超出四天时说明当前支持范围。

### 2.2 不支持

- 沿途天气、路线起终点天气对比、天气对路况或 ETA 的影响。
- 实时预警、空气质量、台风路径、积雪、积水等高级天气能力。
- 多城市同时查询、按 GPS 自动定位城市、从当前路线自动推断城市、从完整聊天历史猜测城市。
- 历史天气、长期预报、按小时预报。
- 天气引发的路线改线或下单建议。

## 3. 使用场景

| 场景 | 示例 | 系统行为 |
| --- | --- | --- |
| 单城市单日 | “杭州明天天气” | 解析城市和日期，返回明天预报 |
| 未指定城市 | “明天会下雨吗” | 上一轮是同一会话的天气回答时，复用其城市并说明“按你刚才说的杭州查”；没有可复用上下文时请乘客补充城市，不猜 GPS 或路线城市 |
| 天气追问 | “杭州明天天气” → “后天呢” | 复用杭州查询后天，并在回答中说明“按你刚才说的杭州查：…” |
| 待补城市 | “后天会下雨吗” → “德清” | 记住原问题的“后天”，用德清继续天气，不再问起终点 |
| 只问今天 | “杭州天气怎么样” | 默认今天 |
| 超出范围 | “下周六杭州天气” | 说明只能查今天到后天、大后天 |
| 城市不存在 | “不存在市今天天气” | 说明没有找到城市，请补充省份或换名称 |
| 天气服务失败 | 高德超时/无权限 | 返回“天气服务暂时不可用，请稍后重试”，不编造天气 |
| 路线问题 | “这条路线经过五常收费站吗” | 仍走路线核查，不被天气 skill 抢走 |

## 4. 业务规则

1. **意图优先级**：只有天气是唯一诉求时才进入 `WEATHER_QUERY`。消息同时给出路线起终点，或明确要求规划、改线、核查当前路线时，仍按对应路线意图处理。
2. **城市来源**：本轮文字中的城市优先。没有城市时，只有同一会话上一轮已持久化的天气回答可以复用其城市；不得跨会话、从当前路线、GPS、地图页或完整聊天历史推断。复用必须在回答中明确说明，乘客可用显式城市覆盖。
3. **日期语义**：今天=0、明天=1、后天=2、大后天=3；未指定日期按今天；明确超出四天为不支持。问城市时要在服务端保存原问题的日期偏移，下一轮只回城市时继续天气。
4. **事实来源**：天气、温度、风向和风力只来自高德预报；缺失字段显示“天气信息暂缺”或“气温暂缺”，不补造。
5. **城市粒度**：高德返回城市或区县级预报，不代表具体路口、路段或室内地点；回答不声称路线级精度。
6. **上下文边界**：天气 skill（map-service）不保存天气上下文；passenger-api 只从上一轮已持久化的天气消息恢复城市，并在问城市的追问 payload 中保存短时 `weatherContext.dayOffset`，供下一轮只回城市时继续天气。缺城市且没有可复用上下文时，请乘客重发完整问法；不产生 `route-check.choices`，不修改当前路线。
7. **安全**：高德 Key 只在服务端；内部调用使用 `X-Internal-Service-Token`；日志不记录完整聊天正文。

## 5. 验收标准

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| AC-W1 | “杭州明天天气” | 返回杭州明天（日期）天气、温度和风力；不调用路线准备或核查 |
| AC-W2 | “明天会下雨吗” | 有上一轮同会话天气上下文时复用城市并明确说明；没有时返回请补充城市的追问，不猜 GPS 或路线城市 |
| AC-W3 | “杭州下周六天气” | 说明只能查今天到后天、大后天，不调用高德 |
| AC-W4 | 城市不存在 | 返回“没有找到城市”，不产生 `turn.failed` |
| AC-W5 | 高德超时/无权限 | 返回 `AI_WEATHER_UNAVAILABLE`，提示天气服务暂时不可用 |
| AC-W6 | “从 A 到 B，这条路线经过 X 吗” | 仍按路线核查处理，天气 skill 不抢意图 |
| AC-W7 | 任意天气轮次 | 当前路线、`routeRef` 和已有路线卡片不受影响 |
| AC-W8 | “杭州明天天气” → “后天呢” | 复用杭州，回答明确说明“按你刚才说的杭州查”；改说“上海呢”时用上海覆盖 |
| AC-W9 | “后天会下雨吗” → “德清” | 用德清和“后天”继续天气，回答德清后天天气，不进入路线起点追问 |

## 6. 后续可扩展

- 多城市对比、沿途天气采样、天气预警。
- 结合当前路线起终点的“出发地/目的地天气”快捷问法。
- 天气对出行建议的解释性回答（必须有明确数据来源，不推断路况）。

上述能力不在第一版验收范围内。
