# 乘客端个人中心「我的订单」二期 PRD

> 本文档描述乘客端个人中心新增「我的订单」页面的产品口径与验收标准。
> 接口契约见《乘客端_个人中心_我的订单_API.md》，技术实现见《乘客端_个人中心_我的订单_TECH.md》，测试用例见《乘客端_个人中心_我的订单_TEST.md》。

---

## 1. 背景与目标

- 乘客在个人中心可以查看历史订单，方便快速回看行程、识别已取消订单。
- 本期目标是新增「我的订单」页面，支持三种筛选：
  - `全部`
  - `待出发`
  - `退款与取消`
- 列表按时间倒序展示。
- 每条订单展示 3 个按钮：
  - `申请开票`
  - `呼叫返程`
  - `评价`
- 本期只做展示，不实现这 3 个按钮的业务动作。

---

## 2. 范围说明

### 2.1 本期交付

- 个人中心入口新增「我的订单」
- 订单列表页支持筛选切换
- 列表按下单时间倒序
- 每条订单卡片展示基础信息与 3 个按钮占位

### 2.2 本期不做

- 不做「申请开票 / 呼叫返程 / 评价」真实业务流转
- 不做退款结算、开票流程、返程叫车的完整闭环
- 不做订单卡片复杂状态解释，只保留列表和详情所需基础信息

---

## 3. 页面口径

### 3.1 入口

- 入口位置：乘客端个人中心
- 页面名称：`我的订单`

### 3.2 筛选标签

- `全部`
- `待出发`
- `退款与取消`

### 3.3 列表排序

- 按订单创建时间倒序
- 最新订单排在最上方

### 3.4 卡片展示

每条订单卡片建议展示以下内容：

- 订单号
- 起点地址
- 终点地址
- 当前状态
- 预估金额 / 实付金额
- 司机信息（如已指派）
- 创建时间 / 完成时间 / 取消时间等关键时间点
- 3 个按钮占位：
  - `申请开票`
  - `呼叫返程`
  - `评价`

### 3.5 按钮口径

- 本期按钮只展示，不可点击或点击后提示“功能开发中”
- 不要求接入真实业务

---

## 4. 当前实现口径

> 以下口径与当前仓库实现保持一致，便于联调。

- `全部`：返回乘客本人所有订单
- `待出发`：当前按可出行/未结束订单归并，包含 `CREATED / ASSIGNED / PENDING_DRIVER_CONFIRM / ACCEPTED / ARRIVED`
- `退款与取消`：当前按 `CANCELLED` 归并
- 退款能力后续若单独落状态，可再扩展该筛选口径

---

## 5. 验收标准

- 可从个人中心进入「我的订单」
- 三个筛选标签切换后列表结果正确
- 列表按时间倒序
- 每条订单可看到 3 个按钮占位
- 按钮本期不触发真实业务
- 页面在联调环境可访问
