# 司机端下周开发 TODO：行程记录与今日运营数据

> 计划周期：2026-07-20 至 2026-07-24  
> 本周目标：完成司机端“行程记录 → 行程详情 → 今日运营看板”闭环。  
> 优先级说明：下面 3 项为下周 P0，其他功能仅进入后续候选池。

## 一、P0：行程记录

### 功能大纲

- [ ] 新增司机端“行程记录”页面，替换首页现有待开发入口。
- [ ] 支持“全部 / 已完成 / 已取消”筛选。
- [ ] 支持分页、下拉刷新、空数据和加载失败状态。
- [ ] 列表项展示订单号、状态、起终点、下单/完单时间、里程、时长和订单金额。
- [ ] 点击列表项进入对应行程详情。
- [ ] 后端按当前登录司机 `driverId` 查询，禁止查看其他司机订单。

### 拟定接口

```text
GET /driver/api/v1/profile/orders?status=&pageNo=&pageSize=
```

### 验收要点

- [ ] 已完成、已取消及无数据场景展示正确。
- [ ] 连续分页不重复、不丢数据，排序规则稳定。
- [ ] 伪造 `driverId` 或订单号时无法越权查询。

## 二、P0：今日运营看板

### 功能大纲

- [ ] 在司机工作台展示今日运营数据。
- [ ] 展示今日完成单数、今日订单总金额、服务里程、服务时长和取消单数。
- [ ] 展示最近一笔已完成行程，可跳转至详情。
- [ ] 支持手动刷新，司机完单后自动刷新看板。
- [ ] 统计口径按 `Asia/Shanghai` 自然日处理，后端返回统计起止时间。

### 拟定接口

```text
GET /driver/api/v1/dashboard/today
```

### 口径约束

- 下周页面使用“订单总金额”，不使用“司机收入”。
- 当前司机、车队、平台的分账规则尚未定版，本周不开发可提现余额、司机净收入或对账功能。
- 订单金额优先使用已完成订单的 `finalAmount`，缺失时是否用 `estimatedAmount` 需在开发前统一口径。

### 验收要点

- [ ] 跨天、零订单、完单后刷新场景统计正确。
- [ ] 看板数据与行程记录在同一统计口径下可对上。

## 三、P0：行程详情

### 功能大纲

- [ ] 展示订单号、业务状态及中文状态说明。
- [ ] 展示上车点、目的地、城市和产品类型。
- [ ] 展示下单、接单、到达、开始、完单/取消时间线。
- [ ] 展示预估金额、最终订单金额、里程和时长。
- [ ] 已取消订单展示取消方与取消原因。
- [ ] 展示车队和服务车辆摘要；数据缺失时正常降级。
- [ ] 预留“对此订单有疑问”入口，本周仅展示客服提示，不建设完整工单系统。

### 拟定接口

```text
GET /driver/api/v1/profile/orders/{orderNo}
```

### 验收要点

- [ ] 已完成和已取消订单的字段、时间线展示正确。
- [ ] 非当前司机订单统一按 404 处理，避免暴露其他司机订单是否存在。
