## 4. 一致性要求

1. 所有相对链接必须指向重命名后的文件。
2. 不再将完单结算自动编排描述为“尚未贯通”。
3. 明确当前是本地模拟支付闭环，不表述为已接入真实支付宝或微信金融能力。
4. 明确支付失败不做后台定时自动重试，乘客可以主动选择 `ALIPAY` 或 `WECHAT` 再次支付，持续异常时联系运营。
5. 明确存在未结清订单时禁止创建新订单。
6. 司机金额展示以及车队/运营公司固定金额或比例分成继续作为后续专项，不误写为本期已实现。
7. 原有未跟踪讨论稿由本次任务正式纳入文档维护范围，但不覆盖或丢失其历史讨论内容。
