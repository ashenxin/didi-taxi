# 文档中文化与实施状态同步实施计划

> **供执行者使用：** 必须按任务顺序执行并逐项核验；本计划仅修改文档与 `AGENTS.md`，不修改业务代码。

**目标：** 将完单结算专项文档统一为直观的中文名称和中文说明，并把已完成的本地模拟结算闭环同步到所有相关文档及项目协作指南。

**实施方式：** 保留计划、设计、接口、联调和讨论文档的职责边界，通过 Git 重命名保持历史连续性，再按实际代码能力更新状态、链接和索引。技术标识保持英文原文，文档性标签和说明使用中文。

**涉及技术：** Markdown、Git、`rg`、Shell 链接校验。

## 全局约束

- 日期前缀保留为 `2026-07-17`，主题和文档类型使用中文。
- 类名、方法名、字段名、HTTP 路径、状态枚举、配置项和命令不翻译。
- 只描述已经验证的 MVP 本地模拟支付能力，不宣称已接入真实支付宝或微信金融服务。
- 支付失败后不进行后台定时自动重试；乘客主动选择 `ALIPAY` 或 `WECHAT` 再次支付，持续异常时联系运营。
- 未结清订单会阻止乘客创建新订单。
- 司机金额展示以及车队/运营公司固定金额或比例分成仍为后续专项。
- 后续 Git 提交信息统一使用中文。
