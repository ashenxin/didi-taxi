控制面保存流程事实；业务域保存业务事实。新增业务通过注册参与者接入，而不是修改注销主方法。

生命周期中心的数据骨架

表 / 聚合主要职责关键唯一约束
customerlifecycle_status、lifecycle_version、auth_epoch、当前 operationcustomer.id；active phone
account_lifecycle_operation一次换号/注销的请求、状态、请求哈希、不可逆标记account_id + type + idempotency_key
account_lifecycle_step参与者步骤、重试、超时、结果和错误operation_id + step_code
account_lifecycle_blocker结构化阻断项、资源、解决动作和解除状态operation_id + domain + blocker_key
account_lifecycle_event状态迁移与人工操作审计event_id
account_lifecycle_outbox可靠发布命令/事件event_id
customer_phone_binding_history手机号绑定版本、起止时间、变更原因和历史身份哈希customer_id + binding_version
通信分层
同步 Check：生命周期中心 → 各领域只读检查端口 → 结构化 blockers
异步 Command：本地 Outbox → Kafka command → 目标领域幂等执行
异步 Result：领域本地事务提交副作用 + Inbox → Kafka result → 中心推进 Step
恢复扫描：XXL-Job 扫 RETRY_PENDING / 超时 Step，重新投递同一 operationId + stepCode

参与者只实现统一语义

check(context) → PASS / BLOCKED(blockers[])
plan(context) → LifecycleStepDefinition[]
execute(operationId, stepCode, accountId, lifecycleVersion) → SUCCEEDED / RETRYABLE / MANUAL
query(operationId, stepCode) → 用于“响应丢失、成功未知”的主动对账
