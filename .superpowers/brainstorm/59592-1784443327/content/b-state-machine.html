B 方案 · 账户状态与注销操作状态分离

账户只表达能否继续开展业务；Operation 负责表达注销流程走到了哪一步。

账户生命周期（低基数、稳定）
ACTIVE　→　CANCELLING　→　CANCELLED
在不可逆清理开始前：CANCELLING → ACTIVE（用户撤销）
冻结、封禁仍由独立 businessStatus 表达，不与生命周期状态做枚举笛卡尔积。
注销 Operation（可观测、可恢复）
REQUESTED → FENCED → VALIDATING
VALIDATING → BLOCKED → VALIDATING　（用户完成行程、支付欠款后自动复检）
VALIDATING → EXECUTING → COMPLETED
任一执行步骤 → RETRY_PENDING → EXECUTING
超过阈值或需要运营裁决 → MANUAL_REVIEW → EXECUTING / COMPLETED
FENCED / BLOCKED → ABORTED　（仅限 irreversibleStarted=false）

CANCELLING 状态的操作门禁

动作类型代表动作门禁原因
解阻动作取消订单、完成行程、支付欠款、提交退款材料允许帮助消除 blocker
只读与取证订单/账单/退款进度、下载必要凭证允许保障用户知情与售后
增加风险新下单、领券、签到、兑换、签免密、绑卡拒绝禁止新增资产和义务
身份变更再次换号、绑定 OAuth、修改实名拒绝防止生命周期并发冲突
系统后处理支付回调、退款、对账、发票红冲、收入冲正允许以内部服务身份继续履约

风险项的四类裁决

B

BLOCKER

在途订单、未结清支付、锁券、退款/拒付争议。

A

AUTO_ACTION

关免密、作废未使用券、积分清零、撤销会话和 OAuth。

R

RETAIN

订单、支付、退款、券/积分流水、对账与发票记录。

M

MANUAL

渠道解约失败、长短款、重复扣款、红冲和收入冲正异常。
